# Lane C: Web App — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, offline, phone-friendly web app: drop statements → audit headline + ranked actions + full money view, all on device.

**Architecture:** Vite + React 18 SPA in `apps/web`. Pure logic (PDF line grouping, report selectors, encrypted export) lives in `src/lib/` with Vitest tests; components are thin. Develops against a hand-written synthetic `AuditReport`; the real engine path catches "not implemented" and shows "coming soon".

**Tech Stack:** React 18, Vite 6, TypeScript 5, Vitest 3, `pdfjs-dist` (worker bundled locally), Web Crypto. Charts hand-rolled SVG (no chart lib).

**Spec:** `docs/tasks/lane-c-web.md`, `docs/ARCHITECTURE.md` (Web app), `docs/PRD.md`, contract `packages/engine/src/types.ts`.

## Global Constraints
- Edit only `apps/web/**`; new deps only in `apps/web/package.json`, plus the matching root `package-lock.json` update that `npm install <dep> -w @openpaisa/web` writes (`npm ci` fails without it). Never `packages/engine/**` or other root config.
- Keep `apps/web/index.html` CSP exactly as is; no CDN, no remote fonts, no analytics. `npm run check:no-network` must pass.
- No localStorage/IndexedDB of statements or reports. Only the encrypted export file the user saves.
- PBKDF2-SHA256 ≥ 310,000 iterations; AES-GCM 256, random 16-byte salt and 12-byte IV.
- ₹ always via engine `formatINR`. Responsive down to 360 px; light + dark via `prefers-color-scheme`; every control keyboard-reachable with a visible label.
- Engine functions that may not exist yet (`prepay`, `amortise`) are imported via namespace (`import * as engine`) and feature-checked (`typeof engine.prepay === 'function'`).
- Done = `npm run check:no-network && npm run typecheck && npm test && npm run build` green; `dist/` works from `npx vite preview` with network off; PR titled `Lane C: web app` with screenshots.

## Review Focus
1. **Password-protected PDF**: wrong password → re-prompt with "That password didn't work", cancel → file listed as skipped; never crash the batch.
2. **Unsupported or non-statement file** (a random PDF, an image renamed .pdf) → per-file error card with the engine message and a link to CONTRIBUTING; other files still process.
3. **Engine not ready**: `runAudit` throws → "Analysis engine is coming soon — try the sample data" and the sample button stays usable.
4. **Large statements**: 12 months × 3 accounts (~3,000 rows) — transaction list must virtualise or paginate (50 per page) and search stays responsive.
5. **Wrong passphrase on import** → "Couldn't decrypt — check the passphrase", no partial state.

### Task 2: PDF/CSV ingestion

**Files:** `src/lib/pdfText.ts`, `src/lib/ingest.ts`, `test/pdfText.test.ts`, `test/ingest.test.ts`; add dep `pdfjs-dist` (pin exact current 4.x/5.x version)

**Interfaces — Produces:**
- `groupItemsIntoLines(items: { str: string; transform: number[] }[]): string[]` — group by y (`transform[5]`) within 2 units, sort lines top→bottom, items left→right by x (`transform[4]`), join with single spaces.
- `extractPdfText(data: ArrayBuffer, password?: string): Promise<string>` — pdfjs with `GlobalWorkerOptions.workerSrc` from `import workerUrl from 'pdfjs-dist/build/pdf.worker.min.mjs?url'`; throws `PasswordNeeded` / `PasswordWrong` (custom error classes) on `PasswordException` codes 1/2. Pass `isEvalSupported: false` (the CSP has no `unsafe-eval`). Set no `cMapUrl` or `standardFontDataUrl` that points off-origin.
- `ingestFiles(files: File[], askPassword: (fileName: string, retry: boolean) => Promise<string | null>): Promise<{ statements: ParsedStatement[]; errors: { file: string; message: string }[] }>` — CSV files read as text; PDFs via `extractPdfText`; then `parseStatement`.
- [ ] **Step 1: Tests:** `groupItemsIntoLines` with shuffled items on 3 rows (y 700, 700.8, 680) → 2 lines in reading order; `ingestFiles` with injected extractor (export a variant `ingestFilesWith(deps)` for testing) covering: wrong password twice then null → error "skipped"; unsupported text → error with `/Unsupported statement format/`; one good + one bad → 1 statement, 1 error (Review Focus 1, 2).
- [ ] **Steps 2–5:** fail → implement → pass → commit.
